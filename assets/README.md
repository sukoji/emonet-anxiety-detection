# Required Assets

The final demo (`src/cap.py`) needs local files that are not committed to GitHub due to size or licensing.

Place the following files in this `assets/` directory:

| File | Description |
|------|-------------|
| `FER_student (1).onnx` | Student-trained FER ONNX model |
| `tag10.csv` | Training labels for LDA + SVM anxiety classifier |
| `image.png` | Optional UI background for valence/arousal overlay |

These files are available in the original Google Drive `emonet/emonet5/emonet5/` folder.
