Emotion-Based Anxiety Detection

실시간 얼굴 감정 분석(arousal/valence)과 통계 기반 분류(LDA + SVM)를 결합해 불안 상태를 추정하는 졸업 프로젝트입니다.

Python OpenCV ONNX Runtime scikit-learn

문제 정의

감정 인식 프로젝트는 라벨 출력(행복/슬픔 등)에 그치는 경우가 많습니다. 이 프로젝트는 감정 연속값을 활용해 실제 상태 추정(불안)으로 확장하는 데 집중했습니다.

시스템 파이프라인

  • 웹캠 프레임 수집
  • 얼굴 검출 및 ROI 전처리
  • ONNX 모델 추론으로 arousal/valence 추출
  • LDA + SVM 기반 불안 여부 분류
  • 실시간 오버레이 UI(상태/점수/그래프) 출력
