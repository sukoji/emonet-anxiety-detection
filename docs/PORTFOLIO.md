# 졸업 프로젝트 포트폴리오

## 1) 프로젝트 개요

본 프로젝트는 얼굴 표정 기반 감정 분석 결과를 활용해 사용자의 불안 상태를 실시간으로 추정하는 시스템입니다.  
기존 감정 분류(행복/슬픔 등) 출력에 머무르지 않고, arousal/valence 연속값을 활용한 불안 판별 로직을 결합해 실용성을 높였습니다.

- **주제**: 실시간 얼굴 감정 분석 기반 불안 탐지
- **문제 정의**: 표정 데이터로 심리 상태를 정량화하고 즉시 피드백 제공
- **성과 형태**: 웹캠 기반 데스크톱 실행 데모 (실시간 추론 및 시각화)

## 2) 배경 및 필요성

정신건강/상담/감정 컴퓨팅 분야에서는 단순 감정 라벨보다 상태 추세와 위험 신호를 빠르게 포착하는 것이 중요합니다.  
특히 비침습적인 카메라 입력만으로 감정의 연속적 변화를 측정할 수 있다면 접근성이 높고 확장성이 큽니다.

이 프로젝트는 다음을 목표로 했습니다.

- 실시간성 확보 (프레임 단위 추론)
- 정성 감정 라벨 + 정량 지표(arousal/valence) 결합
- 최종 사용자에게 직관적인 화면 피드백 제공

## 3) 시스템 아키텍처

### 입력/처리/출력 파이프라인

1. **입력**: 웹캠 프레임 수집
2. **전처리**: 얼굴 검출 및 ROI 추출, 모델 입력 크기 변환
3. **추론**: ONNX 모델 추론으로 arousal/valence 획득
4. **분류**: LDA + SVM으로 불안(Yes/No) 예측 및 score 산출
5. **시각화**: 얼굴 박스 색상, 상태 텍스트, valence/arousal 바/좌표 오버레이

### 구현 포인트

- 멀티스레드 구조로 웹캠 읽기와 배치 처리 분리
- 큐 기반 버퍼로 지연 최소화
- 실시간 판단 결과를 지속 표시해 사용자 체감 안정화

## 4) 핵심 구현 상세

### 4.1 실시간 추론 파이프라인

최종본 `cap.py`에서는 프레임 수집 스레드와 추론 스레드를 분리해 처리량을 유지했습니다.

- `frame_queue`: 카메라 프레임 버퍼
- `result_queue`: 불안 분류 결과 버퍼
- 큐가 가득 차면 오래된 프레임 폐기 방식으로 최신성 유지

### 4.2 불안 분류 모델

- 입력 특징: `arousal`, `valence`
- 결측치 처리: 평균 대체(SimpleImputer)
- 표준화: StandardScaler
- 차원 변환: LDA
- 분류기: RBF SVM
- 출력: `anxiety_pred` + 0~100 스케일 score

### 4.3 시각화 UX

- `Anxiety: Yes/No` 상태 텍스트
- score 텍스트
- 얼굴 경계 박스 색상 변경 (안정: 녹색, 불안: 빨강)
- valence/arousal 막대와 좌표 시각화

## 5) 기술 스택

- **언어/런타임**: Python
- **CV/추론**: OpenCV, ONNX, ONNX Runtime
- **ML**: scikit-learn (LDA, SVM), NumPy, Pandas
- **기반 모델**: EmoNet 계열 구현 활용

## 6) 실험 및 확인 내용

- 웹캠 입력에서 얼굴 검출 안정성 확인
- 표정 변화에 따른 arousal/valence 값 변화 관찰
- 불안 분류 결과와 시각화 일관성 확인
- 실시간 루프에서 프레임 처리 끊김 완화 확인

## 7) 문제 해결 경험

### 문제 1: 실시간 처리 지연
- **원인**: 단일 루프에서 입력/추론/렌더링 동시 처리
- **해결**: 스레드 분리 + 큐 기반 비동기 파이프라인

### 문제 2: 상태값 해석 어려움
- **원인**: 숫자 기반 출력만으로 사용자 이해 한계
- **해결**: 상태 텍스트 + 색상 + 그래프 오버레이 추가

### 문제 3: 감정 라벨과 불안 판단 연결
- **원인**: 다중 감정 분류 결과만으로 불안 판단이 직접적이지 않음
- **해결**: arousal/valence를 별도 특징으로 재가공해 이진 분류기 결합
