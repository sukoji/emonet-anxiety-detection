# 졸업 프로젝트 포트폴리오

## 팀 트라이포스 (Tripos)

| 항목 | 내용 |
|:---|:---|
| 소속 | 상명대학교 |
| 유형 | 졸업 팀 프로젝트 |
| 행사 | 2024 졸업 포트폴리오 페스티벌 (2024.11.04–11.05) |
| 팀원 | 김성현, 변성호, 안성찬, 임재영, 진석호 |

**프로젝트명:** 보이스피싱 피해자 방지를 위한 얼굴 표정인식 및 머신러닝 활용 ATM 감성인식 시스템의 개발

---

## 1. 프로젝트 개요

ATM 이용 중 보이스피싱 피해를 예방하기 위해, 카메라 기반 얼굴 표정 인식으로 사용자의 감정·불안 상태를 실시간 추정하는 시스템을 개발했습니다.

기존 ATM 경고 메시지의 한계를 넘어, **감정 인식 → 불안 탐지 → 상담원 연결/경고**로 이어지는 능동적 보호 체계를 목표로 했습니다.

---

## 2. 배경 및 필요성

- ATM 사용 중 보이스피싱 등 금융 범죄 위험
- 단순 경고 문구의 실효성 부족
- 한국인 얼굴에 특화된 감정 데이터·모델 필요 (EmoNet 등 외국인 중심 모델의 한계)

---

## 3. 데이터

- **출처:** AI-Hub 한국인 감정인식을 위한 복합 영상 (~50만 건)
- **감정 7종:** 기쁨, 당황, 분노, 불안, 상처, 슬픔, 중립
- **전처리:** EmoNet으로 arousal/valence 추출, 카테고리별 ~7만 장 균등 분포 확인
- **라벨링:** Image_path + Emotion 수치 매핑, 이진 분류용 scatter plot 구성

---

## 4. 시스템 아키텍처

1. 웹캠/ATM 카메라 프레임 수집
2. KD student model(`fer_student_kd.onnx`)로 arousal/valence 추론
3. LDA + SVM 불안 이진 분류 + Score(0–100)
4. 실시간 UI: Anxiety Yes/No, Valence/Arousal 그래프

**모델 스택 (발표 기준)**
- RetinaFace: 얼굴 검출
- FAN: 랜드마크 정렬
- EmoNet: 감정 차원 추정
- Knowledge Distillation: MobileNetV2 student 경량화
- LDA + SVM: 불안 분류

---

## 5. 핵심 성과

### 경량 FER (Lee et al. 2023 기반)
- Teacher EmoNet 16.99 GMAC → Student 0.3 GMAC
- Expression Accuracy 73.36%, CPU 실시간 추론 가능

### 불안 탐지 (SVM)
- Accuracy **86%**
- Anxiety Recall **0.96** (실제 불안 상태 포착에 강점)
- 하이퍼파라미터로 고감도/저감도 모드 전환 가능

---

## 6. 기대 효과

- 보이스피싱 직전 단계 고객 보호
- 고령자·장애인 키오스크 이용 지원 확장 가능
- 은행 인-bank 키오스크 안전성·신뢰성 강화
